# 自媒体AI工作台

一套装在你电脑上的自媒体工作台。账号分析、选题、写稿、发布复盘都在同一个界面里完成：
**AI 负责跑流程，你负责拍板。**

数据全部落在你自己选的文件夹里，不上传。

## 它解决的是什么

内容做不起来，多数时候不是"不会写"，是这三件事没答案：

- 同一个赛道，别人的内容为什么有流量？拆清楚了吗？
- 下一篇到底发什么？有依据还是拍脑袋？
- 发完之后，哪一条行、为什么行，回头看得见吗？

这套东西把这三件事串成一条线：**看别人 → 看自己 → 定选题 → 出稿 → 发 → 复盘**，每一步都有落盘的文件，不是聊完就没。

## 能做什么

**看别人：对标分析**

把你关注的同赛道账号和内容建档，AI 拆它的账号结构、内容套路、爆款原因，输出一份正式报告。
不是给你一堆截图，是拆成"它靠什么吸引人、靠什么留住人、怎么建立的信任"。

**看自己：账号诊断**

自己的账号也能体检。基础数据、每条内容的表现、和同类的差距、现在最该改的那一件事。
支持小红书、抖音、B站。

**沉淀规律**

拆过的内容会沉淀成可查的规律和特征词典。下次写稿可以直接对照，不用每次从零想。

**定选题**

三条路，按你的情况挑：

- 搜索选题 —— 给个关键词，去平台搜同题内容，出一批带评分的推荐，附累计点赞收藏评论
- 推荐选题 —— 从你已经沉淀的规律里推，不用再搜
- 选题分析 —— 已经有想法了，让 AI 判断值不值得做、为什么

**写内容**

从选题到初稿到终稿，中间带一次内容审查（查的是表达和结构，不是错别字）。

**发完复盘**

发布记录回填之后，哪条行、为什么行，进复盘。规律是攒出来的，不是猜出来的。

## 界面长什么样

- **工作台**：一个本地网页。账号、内容、选题、报告都在这里按页摆好，点条目看详情
- **对话区**：AI 在这边干活。你从工作台点一个技能，指令自动排进对话
- **跑完自己回来**：这一轮做完，界面自动切回工作台并停在对应的产出页，不用自己找

## 数据在哪

全部在你第一次选的那个文件夹里：

```
<你的工作区>/
  我方资料/     自己的账号、内容、发布记录
  对标资料/     对标账号和内容
  .meiling/     配置和运行状态
```

换电脑就把这个文件夹拷走。不上传，不联网存你的内容。

## 开始用

1. 装好之后第一次打开，选一个文件夹当工作区（空的也行，会引导你装一份）
2. 跟着引导绑定第一个账号，跑一次诊断 —— 这一步顺便把工作台首页填满
3. 之后点技能卡片就能用：选账号分析、搜选题、写内容

## 环境要求

- macOS 或 Windows
- 本机需要 Chrome（取数据要用浏览器，没装的话首次会提示并给出下载地址）
- 取数只读公开页面和创作者中心，不改你的账号，不发内容

## 说明

- 这是自用版：一套工作台对应一个工作区，没有多租户、没有付费闸门
- 分析结论都有对应的正式文件落盘，可以自己打开看，不是只存在于对话里
