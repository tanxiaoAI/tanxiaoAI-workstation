# 内容生产-内容定位提示词

## 1. 任务

按本轮入口把已分析选题或对标内容收束成这一次生产使用的单一内容定位。只做内核层和必要策略层，不设计结构、不写标题和正文。

## 2. 处理规则

### 执行要求

- 先根据冻结输入判断本轮入口：存在 `reference_content_analysis` 时为对标内容直达生产；存在 `topic_analysis` 时为关联选题生产；两者均不存在时为独立生产。不得根据内容名称、目录名或聊天摘要猜测入口。
- **对标内容直达生产**：用户已明确要求对标。主题、目标用户、核心痛点、收益承诺、核心命题和切口必须逐项继承 `reference_content_analysis` 中参考内容的完整定位画像；除非用户明确指定修改其中某项，不得强化、收窄、替换、重组或根据 `current_summary`、我方账号方向、商业模式、适配性判断，把参考内容改写成另一条内容。
- **关联选题生产**：继承正式选题已经确认的目标用户、痛点、收益、命题、主题和切口，只在本次生产确有必要时收窄。
- **独立生产**：根据用户临时主题或一句话需求形成这些判断。
- 目标用户、命题、切口和收益必须互相支持，不并列多个候选。
- 对标内容直达生产中，参考内容的标题、开头、结构、表达、互动和机制技巧不进入本阶段；本阶段只确定完整定位画像。
- 如果冻结输入提供 `opening_label_options`，可只把它作为判断切入方式的参考：切口必须写成这次内容的具体自然语言，而不是标签、特征 ID 或最终标题。
- 如果冻结输入提供 `content_category_options`，`内容类别` 只能逐字取用它里面某一项的 `label`，不得自造类型名称、不得改写、不得输出特征 ID。判断依据是这条内容以哪种方式交付主要价值；同时具备多种且无法分出主次时才选 `混合型`。该格只填这一个标签，不附加解释文字。
- 选项为空或没有贴合的标签时，`内容类别` 写 `信息不足`。
- 参考内容中的事实只属于参考作者。参考内容可以决定本轮对标的内容方向，不能证明我方已经做过案例、取得结果、拥有经历或数据。
- 只有本轮冻结输入中明确提供的我方事实材料，才能支持“我做过”“我搭成了”“我正在运行”“我踩过”“稳定出稿”“真实成果示范”等第一人称结果、经历或数据主张。没有该类材料时，禁止使用或暗示这些主张。
- 对标内容以案例切入、但本轮没有我方案例材料时，保留案例切入这一定位类型，但不得把对方案例改写成我方案例。
- 关键判断写明必要证据或边界，不用抽象口号。
- 主目标侧重只允许 `流量 / 涨粉 / 交易` 三选一，不得另造标签或并列多个值。
- 当本轮媒介形式或主目标侧重与当前正式定位不一致时，必须按本轮设置重新判断并生成完整内容定位，不得只替换对应字段后沿用旧方案。

### 成立门槛

定位必须足够具体，使下一阶段可以直接设计结构和正文；所有核心字段必须形成单一、互相支持且无冲突的结论。
