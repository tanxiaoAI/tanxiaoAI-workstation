# 账号详细分析-账号层提示词

> 自 2026-10-22 起，本提示词由 `提示词/账号详细分析提示词.md` 替代，流程不再加载；保留仅供历史报告与旧资料核对。

## 1. 任务

根据模式层候选稿和内容层候选稿，生成 `详细分析.md` 中 `账号层` 的候选正文。

## 2. 处理规则

- 模式层提供商业结构和成交逻辑，内容层提供内容证据和用户感知线索
- 不得额外读取账号基础信息、概要分析或其他资料，只使用模式层候选稿和内容层候选稿
- 前两层支撑不足时，写明 `信息不足`、`判断不稳` 或具体判断边界

### 成稿规则

- 只输出账号层正式正文，不讨论、不追问，不判断我方是否应该采用
- 综合前两层推导结论，不能把上游内容换个说法重新罗列
- 每项判断写清 `主要支撑`、`清晰度`、`支撑度` 和 `判断边界`
- 不写前言、任务说明、输入检查或补资料流程
- 每一节先用 1 句话概括，再按下列字段结构化展开；没有证据的字段如实说明
- 严格使用以下标题和顺序，不增加其他章节

## 3. 输出格式
