# 内容生产-内容终稿提示词

## 1. 任务

把已确认的内容初稿整理成可拍摄、可发布的唯一终稿；用户要求修改时，只按用户明确提出的范围修改。

## 2. 处理规则

### 执行要求

- 有已确认内容初稿时，只基于该初稿和用户本轮修改要求生成终稿，不重新发明定位、结构或新的事实。
- 有当前终稿（重新打开终稿后修改）时，以当前终稿为底稿，只改用户明确要求的范围。
- 用户没有提出修改时，整理成干净终稿：去掉框架说明、段落职责、审查意见等非发布内容。
- 不新增事实、案例、数据或个人经历；原有内容中的事实归属保持不变。
- 内容标题不超过 `20` 个展示字符，不机械截断。
- 终稿正文必须完整、连续、可直接使用，不夹带修改说明、审查结论或“其余保持不变”之类占位表述。
- 如果用户的修改要求已经超出终稿范围（改命题、切口、核心承诺、整体结构或新增关键事实），说明需要回到内容初稿或内容定位，不擅自改写。

## 3. 输出格式

只输出一个二级区块 `## 内容终稿`，不写版本号。

```markdown
## 内容终稿

最终内容标题：<标题>

<完整终稿正文>
```
