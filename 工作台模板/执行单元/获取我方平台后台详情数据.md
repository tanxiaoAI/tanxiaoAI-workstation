# 获取我方平台后台详情数据

## 输入

```yaml
内容ID: string
平台: 小红书
平台原生内容ID: string
对外页面链接: string
账号ID: string
标题: string
发布时间: string
输出路径: string
```

说明：

- `内容ID` 必填，用于保证后台结果仍然属于上游已经确认的内容
- `平台` 必填，当前版本固定只允许 `小红书`
- `平台原生内容ID`、`对外页面链接`、`账号ID` 必填，三者用于把后台详情硬绑定到公开页中的同一内容和同一账号
- `标题` 必填
- `发布时间` 建议必填
- `输出路径` 必填，必须位于 `.meiling/staging/<当前流程>/<run_id>/`

后台详情是私有指标唯一来源。公开页或 JustOneAPI 的点赞、评论、收藏等字段只能用于身份交叉校验，不得替代本页的四组后台指标。

## 处理

### Chrome 页面操作规则

创作服务平台是动态页面。页面定位、滚动、翻页、展开和点击必须由当前 AI 根据最新页面快照理解真实页面后完成，不得把页面假定为固定 DOM 结构。

### 受限采集状态机

后台详情采集必须按以下状态顺序推进。每次只处理当前状态的一个明确目标，达到完成条件后才进入下一状态；不得在同一轮中反复猜测页面结构、字段含义或下一步动作。

| 状态 | 当前目标 | 允许动作 | 完成条件 | 无法完成时 |
| --- | --- | --- | --- | --- |
| `S0 输入确认` | 校验平台、发布时间和冻结身份 | 读取输入 | 输入完整且平台为小红书 | 按既有失败规则结束 |
| `S1 列表就绪` | 确认登录和日期范围 | 打开列表页、读取快照 | 已登录且日期范围覆盖发布时间 | 日期不覆盖时按日期范围规则等待用户 |
| `S2 候选定位` | 按既有列表定位规则找到唯一候选内容行 | 只使用当前规则允许的可见身份信息；必要时一次定向滚动、翻页或展开 | 找到一个候选行及其详情入口 | 重复页、没有新候选或定位入口不可用时结束 |
| `S3 详情打开` | 进入候选行的详情页 | 点击当前快照中的详情入口、检查标签页 | 当前或新增标签页真实进入 `note-detail` | 同一入口原样重试一次后仍失败则结束 |
| `S4 身份确认` | 确认详情页属于冻结内容 | 读取最新快照、真实 URL 或页面身份信息 | 平台原生内容 ID 一致；账号身份可确认（页面提供账号 ID 时须一致，页面只显示账号名时按账号名 + 后台归属确认） | 内容身份或账号身份不一致时立即结束 |
| `S5 原样采集` | 依固定顺序采集四组页面数据 | 定位下一数据组、切换该组可见入口、读取快照 | 四组均已采集或明确标记不可用 | 单组定向复核一次后仍不可见，记录缺失并继续下一组 |
| `S6 字段映射` | 将原样数据映射为输出字段 | 仅按本文件映射表填充 | 类型和来源均满足规则 | 字段留空并写入口径告警，不得猜测或换名补值 |
| `S7 写入` | 写入唯一输出文件 | 取得系统时间、原子写入 JSON | 文件真实存在且可解析 | 按既有写入失败规则结束 |

`S2` 中的滚动、翻页或展开必须服务于当前缺失的候选行：每次动作后都重新读取快照，并确认出现了新内容、页码变化或新的筛选状态。页面内容和定位状态均未变化时，不得重复同方向操作。不得为了“把字段填满”回到列表页反复探索。

### 过程回执与上下文纪律

执行过程只报告状态变化，不逐字复述完整页面快照、已读取的指标、字段定义或完整 JSON。每次状态变化最多保留：`当前状态 / 已完成数据组 / 当前缺失字段 / 下一步动作 / 真实错误`。完整数据只写入本轮唯一 `输出路径`；同一事实后续只引用该路径或状态，不重新展开页面内容。

数据采集与字段映射必须分离：在 `S5` 只记录页面实际出现的“面板名、标签、值、可见说明”；四组采集结束后才在 `S6` 一次性执行映射。采集阶段不得把页面标签自行改写为输出字段，也不得根据数值形态猜测指标口径。

### 日期范围规则（小红书内容分析）

小红书创作服务平台只支持查看近半年内发布的笔记。日期范围只用于在后台列表中定位候选内容，不是后台数据本身；**唯一硬要求是覆盖目标发布时间**，范围本身可以长于一个月（2026-09-14 实测：把范围设成 `2026-05-01` 至 `2026-09-14` 共 4.5 个月，页面正常返回结果）。页面默认范围通常是「今天往前一个月」。

1. 进入列表后，先使用输入中的 `发布时间` 判断当前页面日期范围是否覆盖目标笔记；当前范围已经覆盖时直接继续，不得调整日期。
2. 当前范围未覆盖时，立即暂停本执行单元，向用户说明当前页面日期范围未覆盖目标发布时间，并请用户在创作服务平台页面手动调整为覆盖该发布时间的日期范围。建议优先使用目标发布时间所在自然月；例如目标发布时间为 `2026-05-11`，建议用户调整为 `2026-05-01` 至 `2026-05-31`。日历不支持整月、或用户选择了更长但仍覆盖 `2026-05-11` 的范围时，两种都算满足条件；不得因为范围超过一个月而要求用户重设。
3. 等待期间不得使用 MCP 操作日期选择器、日期输入框、月份前后切换控件或年份选择器；不得尝试截图、双击或其他替代日期操作，也不得写入失败结果或继续定位候选内容。
4. 用户确认已调整后，重新读取最新页面快照，确认日期范围确实覆盖目标发布时间且列表已刷新，再继续定位候选内容。仍未覆盖时，再次说明情况并等待用户手动调整；不得自行重试或改用其他日期操作。
5. 用户明确表示无法手动将范围调整为覆盖目标发布时间，且页面提示或当前可选范围证实目标笔记超过小红书创作服务平台可查询的近半年范围时，才写入失败结果：`目标笔记超过小红书创作服务平台可查询的近半年范围，无法获取后台详情数据`；不得切换年份、扩大范围或继续尝试。

1. 打开页面或页面状态变化后，先等待页面稳定，再取得最新页面快照。
2. AI 综合当前可见的账号、标题、发布时间、内容卡片与页面布局理解目标内容所在位置；页面没有直接显示平台原生内容 ID 时，先定位候选项，进入详情页后再做强校验。
3. 页面首屏没有目标内容时，只能为当前缺失候选行执行一次定向滚动、翻页或展开筛选；日期范围只按本节的人工调整规则处理。每次交互后重新观察页面，确认页面内容、页码或筛选状态发生变化后才可继续下一次定位，不得连续盲点、反复滚动或在缺少新证据时更换字段解释。
4. 滚动、翻页、切换标签、展开菜单、打开弹层或页面重新渲染后，旧快照和旧控件标识立即失效，必须重新取得页面快照。
5. 点击「分析详情」（2026-09-14 实测的操作列入口文案；页面可能改版，语义相同的入口均可）前，先记录当前全部 Chrome 标签页；点击时只使用最新页面快照返回的目标行控件标识，不得假定按钮名称必须完全相同。
6. 点击后立即检查全部 Chrome 标签页。当前标签页已进入 `creator.xiaohongshu.com` 的 `note-detail` 时直接继续；新增标签页已进入 `note-detail` 时，必须先切换到该新标签页再继续。原列表页未跳转不等于点击失败。
7. 当前标签页和新增标签页都没有 `note-detail` 时，等待页面稳定后再检查全部标签页一次。仍未进入时，重新取得列表页快照，对同一目标行的详情入口只允许原样重试一次；重试后再按本规则检查全部标签页，仍没有才停止。
8. Chrome 工具返回 `Successfully clicked` 只表示工具已执行点击，不表示已进入详情页。只有当前标签页或已切换的新标签页 URL 实际进入 `note-detail` 才算成功。
9. 已进入 `note-detail` 后，先根据详情页 URL、页面结构化状态或页面真实身份信息，复核平台原生内容 ID 和账号 ID。**平台原生内容 ID 必须一致**；小红书后台详情页（2026-09-14 实测，且本文件第 10 条禁止使用 `evaluate_script`）只显示账号名、不显示账号 ID，此时账号身份按「账号名与输入一致 + 该页面归属当前已登录账号」确认，并把「账号 ID 由账号名间接确认」写入 `字段口径告警`，账号 ID 一律原样沿用输入值，不得臆造或改写。内容身份不一致时立即停止，不得读取或保存该页数据。
10. 页面操作和数据读取全程禁止使用 `evaluate_script`、`querySelector`、XPath、固定 CSS 类名、固定 DOM 层级或一次性页面脚本，不得用它操作页面；不得使用脚本点击、反查前端路由、猜测 `noteId` 等参数，也不得手工拼接或直接导航到猜测的详情页 URL。
11. `note-detail` 页面的数据只使用可见页面、最新页面快照、截图和当前真实结构化状态读取。按照“`笔记诊断 → 核心数据 → 互动数据 → 观看趋势`”的固定顺序完成 `S5`；每组先原样记录页面标签和值，再进入下一组。笔记诊断、核心数据、互动数据和观看趋势分别按页面原样保存，不因不同区域的同名指标数值不同而判定冲突，不互相覆盖或纠正。
12. Chrome 工具调用返回错误时，保留真实错误，重新确认当前标签页和最新页面快照后，只允许对同一动作原样重试一次。第二次仍失败才停止；不得把工具错误写成平台后台故障，也不得换成脚本、路由或参数猜测绕过。
13. 写入后台详情 JSON 前，必须执行 `date '+%Y-%m-%d %H:%M:%S %z'` 取得当前系统时间，`JSON.数据获取时间` 必须原样使用该命令的本次输出，不得由模型估算、补写或推算。
14. 未登录、权限不足、账号或内容身份冲突、详情指标全空、或输出路径未成功写入时，必须返回失败；不得以公开数据或旧暂存结果降级为成功。

### 数据获取步骤

1. 先检查 `平台`
2. 如果 `平台 != 小红书`，返回失败：`当前版本只支持小红书后台详情数据`
3. 打开 `https://creator.xiaohongshu.com/statistics/data-analysis`
4. 先检查当前是否处于登录状态
5. 如果页面出现登录页、登录按钮或扫码登录提示，返回失败：`当前未登录小红书创作服务平台`
6. 如果页面能正常看到内容列表、`分析详情`、账号名，视为已登录
7. 登录后，列表页只做定位，不在列表页抓数据
8. 用户尚未选择内容时，列表页可见信息中的 `标题 + 发布时间 + 账号` 只用于定位候选项；进入详情页后用 `平台原生内容ID + 账号ID + 详情页 URL` 做技术校验（账号 ID 按第 9 条的降级规则处理）。用户已在上游选择并冻结 `content_id` 后，不再用标题、发布时间或媒介形式重新定位，也不因这些描述性字段与内容库不同而询问用户；只有平台原生内容 ID 或账号身份技术校验失败才返回身份错误。
9. 如果定位失败，返回失败：`未找到对应内容的后台详情页`
10. 定位成功后进入该条内容的 `分析详情`
11. 后续所有后台数据都只从 `note-detail` 详情页读取
12. 固定抓取下面 4 组数据：
   - `笔记诊断`
   - `核心数据`
   - `互动数据`
   - `观看趋势`
13. 每组采集时使用以下受限路径：
   - 先在当前最新快照中寻找该组标题或语义明确的可见入口；存在入口时只点击该入口并重新读取快照。
   - 当前快照已经完整显示该组时直接原样记录，不为同一组额外滚动或切换。
   - 该组内有未见字段时，只允许围绕该组做一次定向复核；第二次仍未出现时，将对应输出字段留空，并把“页面未显示该字段”写入 `字段口径告警`。
   - `笔记诊断` 区域按右侧 5 个按钮原样保存为“类型 -> 诊断摘要”：
     - `流量转化`
     - `互动表现`
     - `视频画质`
     - `内容深度`
     - `开头吸引力`
   - 每条 `诊断摘要` 只拼接右侧摘要行，不带下面的长建议文案；格式示例：`封面点击率6.3% 同类中位数7.5% 超过38%同类作者`
   - 页面只显示比例、得分、提示文案或“超过同类作者”比较时，必须按原标签保存；不得把它改写为数量字段。
14. 四组原样采集完成后，才从上述数据补齐标准化扁平字段：
   - `点赞数`
   - `评论数`
   - `收藏数`
   - `分享数`
   - `涨粉数`
   - `互动数`
   - `曝光数`
   - `观看数`
   - `封面点击率`
   - `完播率`
   - `六维度平均观看时长`
   - `核心数据平均观看时长`
15. 字段映射规则固定如下：
   - `分享数` 固定取 `互动数据.分享数`
   - `点赞数` 固定优先取 `互动数据.点赞数`
   - `评论数` 固定优先取 `互动数据.评论数`
   - `收藏数` 固定优先取 `互动数据.收藏数`
   - `涨粉数` 固定优先取 `核心数据.涨粉数`
   - `互动数` 只可取页面明确标注为数量的字段；`笔记诊断` 里的 `互动表现` 只记录摘要文案，不得把百分比写入“互动数”。
   - `曝光数` 固定取 `核心数据.曝光数`
   - `观看数` 固定取 `核心数据.观看数`
   - `封面点击率` 固定优先取 `笔记诊断.流量转化` 摘要中的 `封面点击率`，拿不到时再看 `核心数据.封面点击率`
   - `完播率` 固定取 `核心数据.完播率`；`笔记诊断.开头吸引力` 中的 `5秒完播率` 只保留在诊断摘要，不得回填为标准“完播率”
   - `六维度平均观看时长` 固定取 `笔记诊断.内容深度` 摘要中的 `平均观看时长`
   - `核心数据平均观看时长` 固定取 `核心数据.平均观看时长`
   - 两个数据组的同名字段不得互相纠正；例如 `笔记诊断` 中的“平均观看时长”和 `核心数据` 中的“平均观看时长”都必须保留各自页面口径，禁止换算、取平均或以其中一项覆盖另一项。
16. 同时原样返回并生成：
   - `内容ID`
   - `平台`
   - `平台原生内容ID`
   - `对外页面链接`
   - `账号ID`
   - `后台详情页链接`，必须是当前实际读取数据的 `creator.xiaohongshu.com` `note-detail` 页面，不得回填列表页或公开内容页
   - `数据获取时间`
   - `数据来源`
17. 如果 4 组关键数据全部为空，返回失败：`后台详情数据为空`
18. 成功或失败都把完整结构化结果写入唯一的 `输出路径`，不得只停留在对话文本中
