# 获取我方平台内容分析数据

## 输入

```yaml
工作区根目录: string
本轮运行标识: string
平台: 小红书 | 抖音
账号ID: string
账号名: string
采集计划路径: string
候选输出路径: string
```

说明：

- 本执行单元只服务「我的账号」详细数据链路。
- `采集计划路径` 由 `创作者中心数据分析采集执行器.py --action prepare` 返回，记录本轮账号身份、平台和可用于匹配的内容清单。
- `候选输出路径` 必须位于本轮暂存目录 `.meiling/staging/self-account-diagnose/<run_id>/创作者中心数据/`。
- 本执行单元只读取页面并写入候选 JSON，不写正式数据；正式数据由 `commit` 动作写入。
- 平台由账号库决定，只支持小红书和抖音；按平台选择下方对应分支，不混用两套页面。

## 小红书（内容分析 → 笔记数据）

### 采集范围（硬约束）

本执行单元只采「内容分析 → 笔记数据」当前页面第一页已经渲染出来的笔记行：

1. 打开 `https://creator.xiaohongshu.com/statistics/data-analysis`，进入「内容分析」的「笔记数据」。
2. 保持页面默认的最近一个月时间范围。**不得点击日期选择器、不得修改开始或结束日期、不得切换月份或年份、不得使用页面提供的任何时间筛选操作。**
3. **不得翻页、不得切换每页条数、不得滚动加载更多、不得点击「下一页」。**
4. 只读取当前页面第一页可见的笔记行，看到几行就采几行；页面显示 3 行就只采 3 行，显示 10 行就只采 10 行。
5. 当前页没有任何笔记行时，`content_rows` 写空数组，并记录真实原因，仍算完成采集动作。
6. 页面显示的时间范围原样记录到 `page_range_text`，不得改写或推算。

> 这条约束的原因是小红书内容分析默认只展示最近一个月的笔记，AI 无法可靠操作日期控件。宁可只覆盖当前可见范围，也不扩大范围或猜测历史数据。

### 分析详情（只针对这批可见笔记）

列表页没有平台原生内容 ID，也没有完播率、2 秒退出率、粉丝占比和观看趋势。要判断内容卡在包装还是留存，并对匹配不到的内容新建档案，必须进入每一条可见笔记的「分析详情」。

规则：

1. 笔记集合固定为第一页可见行。**不得进入列表外笔记，也不得为了「多拿几条」翻页。**
2. 进入详情前先按「笔记管理」确认该笔记是 `公开`；非公开状态不进入详情，直接记录跳过。
3. 对每一条公开且可见的笔记，点击该行的「分析详情」，进入 `creator.xiaohongshu.com` 的 `note-detail` 页面。
4. 进入详情页后先确认身份：标题和发布时间与列表行一致；账号名与当前登录账号一致。平台原生内容 ID 从当前 `note-detail` 页面的真实 URL 中读取，不得猜测或拼接。
5. 按固定顺序采集四组数据：
   - `笔记诊断`：流量转化、互动表现、视频画质、内容深度、开头吸引力；
   - `核心数据`：曝光数、曝光数粉丝占比、观看数、观看数粉丝占比、封面点击率、封面点击率粉丝值、平均观看时长、平均观看时长粉丝值、完播率、完播率粉丝值、2秒退出率、2秒退出率粉丝值、涨粉数；
   - `互动数据`：点赞数、点赞数粉丝占比、评论数、评论数粉丝占比、收藏数、收藏数粉丝占比、分享数、分享数粉丝占比；
   - `观看趋势`：5秒内离开提示值、观看趋势备注。
6. 每组只读取当前页面可见内容，不调整统计周期、不切换日期、不展开额外明细。
7. 采集完成后返回「内容分析」列表页，保持原来的第一页和时间范围，继续下一条；不得因为返回而重新排序、重新筛选或改变可见行集合。
8. 单条详情失败（打不开、身份不一致、字段不可见、日期范围不覆盖）时，记录 `后台详情.状态 = 失败` 和真实失败原因，继续下一条；**不得为了修好这一条去调整日期范围或翻页**。
9. 同一入口原样重试一次仍失败才记为失败；不得连续盲点或反复打开。

### 账号概览

账号级数据读取「账号概览」页，必须采满下面十项（2026-11-01 起）。这十项就是工作台「账号档案」和首页「最近数据」要画的东西，缺一项那张卡就空一块：

| 平台 | 必采指标 |
| --- | --- |
| 小红书 | 统计周期、曝光数、封面点击率、平均观看时长、视频完播率、观看数、涨粉数、主页访客数、发布数、互动数 |
| 抖音 | 统计周期、播放量、互动率、完播率、作品数、粉丝净增、5秒完播率、2秒跳出率、封面点击率、平均播放时长 |

写法：

- **入口是固定的，不能用首页顶栏充数**（2026-11-01 实测踩过）：
  - 小红书：创作者中心首页 → 左侧「数据看板」→「账号概览」，落地地址形如 `https://creator.xiaohongshu.com/statistics/account/v2`。首页顶部的「关注数 / 粉丝数 / 获赞与收藏」是账号主页数据，**不是**账号概览。
  - 抖音：`https://creator.douyin.com/creator-micro/data-center/operation`。
  - 读的是哪一页，就把那一页的完整地址写进 `account_overview.页面链接`。执行器会校验落点：小红书必须是 `/statistics/account` 下的页面，抖音必须是 `/data-center` 下的页面；填首页（`/new/home`）或内容分析页会被直接拒绝，不会落盘。
- `统计周期`写页面上的日期区间原文（如 `10-21 至 10-27`），不换算、不补全。
- 带「环比 ±X%」的指标连环比一起写：`141（环比 +22%）`。
- 带「超过 X% 同类创作者」（抖音是「超过/低于 X% 同类作者」）的指标连排名一起写：`13（超过32%同类创作者）`。
- **关注数、粉丝数、获赞与收藏不写进 `指标`**：它们是账号主页数据，已经在账号库里。只读这页页头那三个汇总数，等于这份概览没采到 —— 这种情况 `状态` 必须写 `未获取`，不要写 `成功`。
- 只读当前可见内容：不调整统计周期、不切换时间筛选、不翻页、不进入二级明细。
- 某一项页面上确实没有（如「暂无数据」「观看数不足 100」）时，这一项写空字符串，`备注` 写真实原因；不要用公开页数据替代，不要补造。
- **十项缺一项都不算采完**：`commit` 回执里 `account_overview_missing` 非空时，按缺的那几项回页面补采一次再提交；补完仍缺的才写空字符串并在 `备注` 里写清是哪几项、页面怎么显示的。

### 视频文案（笔记管理封面入口）

内容列表缺少视频下载链接时，用创作者中心的「笔记管理」入口取视频文案，**不需要登录公开站**。

1. 打开 `https://creator.xiaohongshu.com/new/note-manager`。
2. 按标题和发布时间找到目标笔记；只处理 `公开状态 = 公开` 的笔记，私密、仅自己可见和其他非公开状态不处理。
3. **每条笔记单独打开一个新标签页**，再点击该笔记封面。封面会打开带 `xsec_token` 的公开视频页，例如：
   `https://www.xiaohongshu.com/explore/<noteId>?xsec_token=...&xsec_source=pc_creatormng`
4. 不得在同一标签页连续点击多条封面；浏览器一次只允许一个弹窗，连续点击只会打开第一条。
5. 页面打开后，从当前页面的资源记录或播放器元素里读取视频地址，**只取以 `.mp4` 结尾的地址**（优先 `<video>` 的 `currentSrc`，形如 `…/110/258/xxxx_258.mp4?sign=…`），不得猜测地址，也不得直接拼接 `/explore/<ID>`。`.m4s` 是分片、`.m3u8` 是播放列表，两者都不能交给 ASR（火山对 `.m4s` 返回 `45000151 音频格式不正确`，2026-11-01 实测）；而且 `.m4s` 的签名绑在自己路径上，改扩展名拼不出 `.mp4`（实测 403），只能重新打开页面取。
6. 用当前视频地址调用 `执行单元/获取视频文案执行器.py`，输出：
   - `<内容目录>/视频文案.md`
   - `<本轮暂存目录>/视频文案结果-<内容ID>.json`
7. 单条失败（页面打不开、没有视频地址、ASR 失败）只记录该条，继续下一条；不得要求用户登录公开站，也不得用标题或摘要伪造文案。
8. 笔记管理里标记「仅自己可见」的笔记仍可尝试封面入口；页面打不开时按失败记录，不把它当成公开内容。

## 抖音（数据中心 + 内容管理 + 作品数据详情）

### 账号级数据（数据中心）

1. 打开 `https://creator.douyin.com/creator-micro/data-center/operation`。
2. **不得切换「昨天 / 近7天 / 近30天」，不得点击日期选择器，不得导出数据。**统计周期原样读取。
3. 依次读取页面上三块当前可见内容，写入 `account_overview.指标`：
   - `数据总览`：`统计周期`、`播放量`、`互动率`、`完播率`、`作品数`、`粉丝净增`；
   - `作品数据`：`作品统计周期`、`投稿量`、`总播放量`、`总点赞量`、`总分享量`、`总评论量`、`5秒完播率`、`2秒跳出率`、`封面点击率`、`平均播放时长`；
   - `粉丝数据`：`粉丝统计周期`、`总粉丝量`、`粉丝净增`、`吸粉量`、`脱粉量`、`回访粉丝量`；
   - `粉丝画像`：`粉丝画像-年龄分布`、`粉丝画像-设备分布`、`粉丝画像-地域分布`，按页面显示的顺序和百分比原样拼接成一段文字。
4. 指标名沿用页面文字，带百分号的保留百分号；数字中的千分位逗号原样保留。
5. 某块数据读不到时，对应指标留空，并在 `account_overview.备注` 写真实原因；不得补 0、不得用公开页数据替代。
6. `account_overview.数据来源` 固定写 `数据中心`，`状态` 至少有一块成功才写 `成功`，三块都读不到写 `未获取`。

### 内容级采集范围（硬约束）

1. 打开 `https://creator.douyin.com/creator-micro/content/manage`，确认位于「作品」列表。
2. **不得翻页、不得切换排序、不得切换体裁或审核状态筛选、不得滚动加载更多。**
3. 只读取当前第一页可见的作品卡片，看到几张就采几张（通常 12 张）；不足一页时按实际数量。
4. 页面显示的时间范围或筛选条件原样记录到 `page_range_text`；数据中心统计周期同时用于账号级说明。
5. 当前页没有作品时，`content_rows` 写空数组并记录真实原因，仍算完成采集。

### 公开状态判定（硬约束）

- 只有页面状态文字为 `已发布` 的作品视为 `公开`，候选里 `公开状态` 写 `公开`。
- `私密`、`审核中`、`未通过` 以及其他任何文字都按非公开处理，候选里 `公开状态` 原样写页面文字。
- 非公开作品只记录列表可见字段，**不进入作品数据详情、不匹配、不新建内容、不取评论、不取视频文案**。

### 作品数据详情（只针对这批公开作品）

3. 进入详情页后先确认身份：页面标题与列表行标题一致、发布时间与列表行一致；不一致时按失败记录，不采集该条。

   `播放量`、`点赞量`、`评论量`、`分享量`、`收藏量`、`弹幕量`、`完播率`、`2s跳出率`、`涨粉量`、`脱粉量`、`粉丝播放占比`。

     响应体包含 `comments` 或 `comment_info_list` 数组，以及 `cursor` / `has_more` / `total` 或 `total_count`；
   - 把该响应原文（不要改写、不要裁剪）保存为 `.meiling/staging/self-account-diagnose/<run_id>/评论/<平台原生内容ID>-评论原始响应.json`；
   - **只保存首屏这一个响应（通常 10 条），不滚动加载更多、不翻页、不回复、不删除**；
   - 评论数为 0 或页面没有发出评论列表请求时，不写该文件，并在 `后台详情.字段口径告警` 记一条真实原因。

> 评论原文由 `2.10` 调用 `执行单元/内容评论抓取执行器.py` 消费该原始响应落盘成正式 `评论.md` / `评论.json`，本步骤只负责保存响应原文。

内容列表缺少视频下载链接时，用「内容管理」的封面入口取视频文案：

1. 在 `https://creator.douyin.com/creator-micro/content/manage` 按标题和发布时间找到目标作品；只处理 `公开状态 = 公开` 的作品。
2. **每条作品单独打开一个新标签页**，再点击该作品封面。封面会打开公开视频页，例如：
   `https://www.douyin.com/user/self?modal_id=<aweme_id>`（或 `https://www.douyin.com/video/<aweme_id>`）。
3. 页面打开后，从当前页面的资源记录或播放器元素里读取视频地址（`mp4`），不得猜测地址，也不得直接拼接 `/video/<ID>`。
4. 用当前视频地址调用 `执行单元/获取视频文案执行器.py`，输出：
   - `<内容目录>/视频文案.md`
   - `<本轮暂存目录>/视频文案结果-<内容ID>.json`
5. 单条失败只记录该条，继续下一条；不得用标题或摘要伪造文案。

## 匹配与新建内容（由 commit 执行器完成）

- 只处理 `公开状态 = 公开` 的行；私密、仅自己可见、草稿、审核中、未通过、其他和未知状态一律跳过，不匹配、不新建内容、不抓详情。
- 先按**标题完全匹配**现有账号内容列表：标题去掉首尾空格后逐字相等，且只命中一条时算匹配。
- 标题命中多条时记为「标题重复」，不新建内容。
- 标题未命中时，再用平台原生内容 ID 匹配一次，避免同一条内容因标题改动被重复建档。
- 标题和原生 ID 都未命中，且后台详情成功时，新建一条内容：分配新的内容 ID、创建内容目录、写入 `创作者中心详情.json`，并回写账号内容列表。
- 后台详情失败时只记录列表行原值，不新建内容，不猜测内容 ID。

## 输出

```yaml
状态: 成功 | 失败
候选路径: string
可见行数: number
账号概览状态: 成功 | 未获取
后台详情成功数: number
后台详情失败数: number
页面时间范围: string
失败原因: string
```

成功时必须写入候选文件并回读校验；失败时说明真实原因，不写正式数据。

## 失败处理

- Chrome 不可用：返回失败，原因写真实连接错误。
- 创作者中心未登录或跳转登录页：返回失败，原因写 `创作者中心未登录`。
- 页面结构变化、找不到对应列表或无法读取行：返回失败，原因写具体缺口；不得改用其他页面或历史缓存。
- 单条详情失败只影响该条，不影响其他可见内容。
- 任何情况下都不得调整时间区间、翻页或切换每页条数来「补齐」数据。
