# 创作者中心链接识别与账号身份解析

本执行单元只负责把用户提供的创作者中心链接转换成本轮唯一账号身份（`平台 / 账号ID / 账号名 / 主页链接`），并输出判定状态；不采集公开主页数据、不写正式 CSV、不展示面向用户的固定文案，也不等待用户选择。

## 输入

```yaml
原始输入: string
本轮暂存目录: string
```

说明：

- `原始输入`：用户消息里的完整内容，可能只有一条链接，也可能是带链接的整段文字
- `本轮暂存目录`：本轮 `run_id` 派生的暂存目录，只用于存放 Network 响应临时文件
- 本执行单元固定使用 `chrome_devtools`，只支持小红书和抖音
- 本执行单元不读取 JustOneAPI 配置，不调用任何付费接口

## 处理

### 1. 提取链接

从 `原始输入` 中提取所有 `http(s)://` 开头的链接：

- 0 条：返回失败 `未识别到链接`
- 多于 1 条：返回失败 `识别到多条链接`
- 正好 1 条：进入 `2. 判断平台`

### 2. 判断平台

只按域名判断，不按路径判断：

- `creator.xiaohongshu.com` → `小红书`
- `creator.douyin.com` → `抖音`
- 其他域名：返回失败 `链接不是创作者中心链接`

两个平台的创作者中心入口都是固定路径，链接里不带账号 ID，账号身份由**你自己 Chrome 的登录态**决定。

这里的「你自己的 Chrome」就是用户平时上网用的那个 Chrome —— AI 通过调试端口接进去（DS 版用 `--auto-connect`），**登录态就是他自己的**：他平时登录过就直接算数，不用再登一次。

### 3. 确认 Chrome 与登录态

1. 先只读调用一次 `mcp__chrome_devtools__list_pages` 检查可用性；不可用时返回失败 `chrome_devtools 不可用`。
2. 新开标签页打开 `原始输入` 中的链接。页面打不开、跳转到无关页面或路径已失效时，改开该平台的固定入口：
   - 小红书：`https://creator.xiaohongshu.com/new/home`
   - 抖音：`https://creator.douyin.com/creator-micro/home`
3. 等待页面加载和跳转完成，判定登录态。出现以下任一情况判为未登录，返回失败 `创作者中心未登录`：
   - 地址栏跳转到登录页、扫码页或 `login`、`passport` 一类路径
   - 页面主体是登录表单或二维码，没有账号信息
   - 页面已加载但没有账号头像、没有账号昵称

未登录时不做后续任何读取动作，不重试、不猜测账号；由上层流程提示用户**在自己正在用的那个 Chrome 里登录**（就是他平时上网那个），不要让他另开浏览器。

### 4. 读取当前账号身份

已登录时，按以下优先级读取当前账号的账号 ID 与昵称：

1. 页面结构化状态；
2. `evaluate_script` 读取当前 DOM 中账号信息区域；
3. 上述两处都取不到账号 ID 时，调用 `list_network_requests`，只查当前页面本次导航产生的 `xhr / fetch` 请求，找到返回当前登录账号资料的响应，再调用 `get_network_request` 写入文件后读取。

平台字段映射：

小红书：

- `账号ID` ← 页面或接口中的 `userId`（兼容 `user_id`、`red_id`）
- `账号名` ← `nickname`

抖音：

- `账号ID` ← `sec_uid`（兼容 `sec_user_id`）
- `账号名` ← `nickname`

约束：

- 不得从 URL 路径猜测账号 ID，不得用页面其他用户或推荐列表里的 ID。
- `get_network_request` 不得内联返回；必须把响应写入 `<本轮暂存目录>` 下的文件再读取，避免带出 Cookie。
- 账号 ID 仍取不到时返回失败 `未取得真实账号 ID`；不得先建档再补。

### 5. 确认账号有已发布内容

1. 打开对应平台的列表页：
   - 小红书：`https://creator.xiaohongshu.com/new/note-manager`
   - 抖音：`https://creator.douyin.com/creator-micro/content/manage`
2. 读取当前可见列表，只统计公开状态的内容：
   - 小红书：`公开状态 = 公开`
   - 抖音：页面状态文字为 `已发布` 才归一为 `公开`
3. 没有任何公开内容时，返回失败 `没有已发布内容`。
4. 列表为空但页面显示加载失败、接口报错或需要重新登录时，返回失败 `内容列表读取失败`，不得归为 `没有已发布内容`。

本步骤只为确认账号有可用于后续诊断的公开内容，不采集内容明细，不做匹配，不新建内容。

### 6. 组合标准主页链接

用第 4 步拿到的 `账号ID` 直接拼，不打开公开页：

- 小红书：`https://www.xiaohongshu.com/user/profile/<账号ID>`
- 抖音：`https://www.douyin.com/user/<账号ID>`

创作者中心给的 `userId` / `sec_uid` 就是主页地址里那个 ID（2026-11-01 实测一致），不需要再开公开页交叉验证。本执行单元因此**不打开任何公开主页**，用户全程只登录创作者中心一个页面。

约束：

- 标准主页链接不得带 `xsec_token`、`xsec_source` 或其他查询参数。
- 不得为了让链接好看去换一个 ID。

### 7. 输出

本执行单元不写业务文件，也不新增正式 JSON；只在对话中返回以下结果。

```yaml
状态: 成功 | 失败
平台: 小红书 | 抖音
账号ID: string
账号名: string
主页链接: string
创作者中心链接: string
失败类型: string
失败原因: string
```

失败类型固定为以下之一：

- `未识别到链接`
- `识别到多条链接`
- `链接不是创作者中心链接`
- `chrome_devtools 不可用`
- `创作者中心未登录`
- `未取得真实账号 ID`
- `没有已发布内容`
- `内容列表读取失败`

## 禁止动作

- 禁止把创作者中心链接当作主页链接直接交给下游取数或建档。
- 禁止在未登录、未取到真实账号 ID 时建档或改用其他入口。
- 禁止在 `没有已发布内容` 时继续诊断，也禁止要求用户改填主页链接来绕过。
- 禁止改写 `我方账号库.csv`、`我方内容库.csv` 或任何正式业务文件。
