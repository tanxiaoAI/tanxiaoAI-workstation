# 自我账号诊断方法论

## 1. 文档目标

本方法论用于比较“当前希望账号做成什么”与“账号实际做成什么”，找出最关键的方向偏差、执行不足和证据缺口；调整动作由《账号改进行动清单》承接，不在诊断里展开。

## 2. 诊断原则

- 以 `我方自媒体规划.md` 中已经确认的自身条件、用户与需求、产品与变现、账号与内容为判断标准；规划不存在或不可用时，回退 `调查问卷.md` 的原始回答
- `我方当前概要.md` 只是规划的摘要，不是独立判断基准，也不参与回退
- 先看实际证据，再形成结论，不用用户愿望代替账号表现
- 先判断是否一致，再判断表现强弱
- 模式层、账号层、内容层分别诊断，并检查三层之间的连带影响
- 区分 `方向偏差`、`执行不足` 和 `证据不足`
- 只收束当前最关键的 0 到 3 个问题，不罗列所有小问题；没有值得优先处理的问题时明确写“当前未发现需要优先处理的关键问题”
- 诊断只回答问题是什么，不写行动方案；具体动作由《账号改进行动清单》承接，诊断本身不直接改写长期规划
- 目标与实际看当前公开面全量，历史存量只给处置建议；这段时间的变化只看上次诊断日之后新增的公开内容，指标也只算新增，不混用历史内容或全量基线

## 3. 判断框架

### 3.1 判断基准

判断基准按账号是否有历史正式诊断分两档：

1. **首次诊断**（该账号没有历史正式诊断）：默认使用 `调查问卷.md` 的原始回答，`我方自媒体规划.md` 不参与本轮目标判断；如果本轮指令明确说明规划刚刚按同一份新问卷更新，并要求以新规划为判断基准，则改用 `我方自媒体规划.md`。
2. **新一轮诊断**（该账号已有正式诊断）：优先 `我方自媒体规划.md`，回答“当前阶段优先做什么、哪些不做”，包括：
   - 主要服务谁、解决什么问题、提供什么价值
   - 账号希望形成什么定位和认知
   - 长期讲什么、如何吸引目标用户并建立信任
   规划不存在或不可用时，回退 `调查问卷.md` 的原始回答。

规划和问卷都没有明确写出的内容，不得补成既定规划；相关诊断只能写 `判断基准不足`。不得把规划与问卷拼成两套并行目标。

**判断基准与账号实际方向完全不一致不是停止条件**：必须照常形成完整诊断，`目标与实际` 三个维度写 `不一致`，问题类型归入 `方向偏差`。只有账号、内容证据或基准文件本身不可用时才停止。

### 3.2 实际证据

账号实际表现主要由下面几类证据共同决定：

| 证据 | 主要用途 |
| --- | --- |
| 账号资料和主页呈现 | 判断用户第一眼如何理解账号 |
| 内容列表和互动数据 | 判断实际发布结构、主题分布和表现差异 |
| 已读取的视频文案 | 只判断对应内容的观点、结构、表达和信任建立方式 |
| 用户补充的反馈、咨询和成交信息 | 判断实际吸引人群和商业承接 |
| 上一版诊断 | 比较变化，不替代当前证据 |

历史 `内容画像与特征卡`（已于 2026-09-27 退役）是旧分析产物，不是本轮原始事实，不得作为诊断证据再次输入。需要判断内容观点、结构和表达时，只使用本轮实际读取并通过校验的视频文案，避免旧结论循环证明新结论。

### 3.3 问题分类

| 类型 | 含义 | 处理方向 |
| --- | --- | --- |
| 方向偏差 | 实际账号正在走向与判断基准（规划或调查问卷）不同的方向 | 先纠正方向，必要时重新确认规划 |
| 执行不足 | 方向正确，但表达、稳定性或完成度不够 | 优先改执行方式 |
| 证据不足 | 当前材料无法支持稳定结论 | 明确边界，不强行判断 |

不能因为数据表现暂时一般就判定方向错误，也不能用“还在早期”掩盖已经出现的明显偏差。

### 3.4 这段时间的变化

这一段不是把上一轮的问题重新分一遍类，也不是记录这个月发了什么，而是判断上次让你改的东西，这段时间到底变好了还是变差了；看不出来时就说明现在处在什么水平。

判断顺序固定：

1. 先看上一版诊断认定的主要问题和判断；
2. 再看上一次《账号改进行动清单》，判断上次让你做的事有没有体现在新增内容和数据里；
3. 再看上次诊断日之后新增的公开内容和同口径指标；
4. 最后给判断：变好、变差、没变、仍然差，还是无法比较。

每条变化只写一个方面，并直接给出结论。只陈述“公开内容从 5 条变成 7 条”“新增了 2 条”这类用户自己就知道的事实，不算诊断；必须说清这对上次的问题意味着什么。

前后对比要同时满足三个条件：看的是同一个方面、用的是同一个指标、样本范围差不多。任一条不满足，只能写 `无法比较`，并在文案里说明当前实际水平，不能说变好或变差。

五种结论对应的情况：

- `变好`：上次的问题确实减轻，且能和上次的同口径数据对上。
- `变差`：上次的问题加重，或出现了可对比的新恶化。
- `没变`：做法和数据都和上次差不多，没有实质推进。
- `仍然差`：上次指出的问题原样存在，当前水平依然不合格。
- `无法比较`：上次没有同口径数据，只能说现在好不好，不能判断方向变化。

`新发现` 和 `新发生` 要分开：这次才拿到的数据暴露的问题只能算新发现，不能写成这段时间新出现的问题。

第 3 节不写「上次行动核对」：上一次行动清单只用来判断问题有没有变化，不逐条核对用户执行到哪一步，也不替用户判断做了或没做。本轮行动清单在诊断之后生成，不参与这段时间的变化判断。

## 4. 三层诊断

### 4.1 模式层

判断账号是否在服务正确的人和价值路径：

- 实际吸引和承接的人是否接近当前目标用户
- 内容持续提供的价值是否接近规划中的核心价值
- 已经存在产品、咨询或成交路径时，账号是否自然连接到正确的下一步
- 当前问题属于承接方向错误、承接较弱，还是暂时没有足够证据

缺少咨询、成交或用户反馈时，可以判断公开内容的承接方向，但不能声称真实转化已经成立或失败。

### 4.2 账号层

判断账号在用户眼中的认知是否接近当前定位：

- 昵称、简介、主页和持续内容共同传递的账号定位是否清楚
- 实际吸引的人是否接近目标用户
- 用户能否快速理解账号提供的核心价值
- 人设风格和差异化是否真实、稳定、可感知
- 当前最脆弱的成立条件是什么

### 4.3 内容层

判断已发布内容是否持续支撑账号定位和价值路径：

- 核心议题和目标问题是否稳定、是否跑偏
- 表达方式是否符合账号定位和目标用户
- 吸引机制带来的是目标用户还是泛流量
- 内容是否通过观点、案例或过程建立正确的信任
- 多条内容合起来是否形成稳定的账号印象

正文级证据边界按内容逐条判断，不按整个账号判断。只有确实读取了视频文案的内容，才能判断其具体观点、正文结构、表达质量或深层信任机制。`selected_basic_only_content_count` 对应的内容只能根据标题、形式、链接和互动数据判断表层分布。

封面、主页和视觉风格只能使用当前 AI 已实际读取的图片。封面链接、图片路径或“已有图片”的字段不等于已读图。

## 5. 收束顺序

1. 明确本轮数据范围和判断边界
2. 和上一版诊断、上一次行动清单比，看这段时间完成了什么、没完成什么、哪些看不出来
3. 分别判断模式层、账号层、内容层的一致与偏差
4. 把每个偏差归类为方向偏差、执行不足或证据不足
5. 找出能够解释多个表面问题的上游原因
6. 只保留最影响账号成立的 0 到 3 个问题；一个都没有时明确说明当前无需优先整改
7. 诊断在第 6 步收束即结束；行动动作由《账号改进行动清单》承接，不在诊断里重复

优先级由“影响范围、问题严重程度、当前是否能行动”共同决定，不按问题数量或单条数据高低排序。

## 6. 结果边界

- 内容列表可能未抓全时，结论只代表本轮已获取范围
- 视频样本较少时，可以形成当前判断，但必须说明样本数量，不能冒充长期规律
- 混合账号中，有正文级证据的内容不能代替没有正文级证据的其他内容
- 媒介类型未确认时，不得将其称为图文或视频
- 图片说明缺失时，不对视觉呈现做确定判断
- 用户反馈、咨询或成交信息缺失时，不对真实用户构成和转化效果做确定判断
- 诊断发现长期规划可能需要改变时，只指出影响和原因；是否修改由 `自媒体规划分析流程` 与用户确认
