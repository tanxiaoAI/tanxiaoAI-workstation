# 选题分析方法论

## 1. 文档目标

本方法论用于把一个选题分析清楚，形成明确、自洽并保留证据边界的选题定义和是否值得做的判断；不负责设计内容形式、表达方式、文章结构或正文写法。

## 2. 分析原则

- 先理解选题，再判断是否值得做，不能先下结论再反向拼理由。
- 先判断选题本身是否成立，再用参考内容补充证据，不能让参考样本代替我方判断。
- 只分析“题是什么、写给谁、解决什么、带来什么、表达什么判断、从哪里切入”，不提前进入内容生产。
- 所有核心要素必须互相支撑；任何一项变化，都要重新检查受到影响的其他要素。
- 信息不足时保留未知和验证边界，不用合理猜测冒充事实。
- 参考内容数据好，只能证明该样本曾经有效，不能直接证明我方照做也会有效。

## 3. 标准推导顺序

| 步骤 | 判断内容 | 形成结果 |
| --- | --- | --- |
| 1 | 这个题表面上在说什么 | 题意理解 |
| 2 | 它属于哪一类问题 | 主题 |
| 3 | 它主要写给谁 | 目标用户 |
| 4 | 这群人当前卡在哪里 | 核心痛点 |
| 5 | 用户看完希望得到什么 | 收益承诺 |
| 6 | 最终希望用户相信什么 | 核心命题 |
| 7 | 从哪个具体角度进入 | 切口 |
| 8 | 六个要素能否互相支撑 | 一致性判断 |
| 9 | 基于前述判断决定是否值得做 | `建议做 / 暂缓 / 不建议做` |

`是否建议做` 是最后形成的结论，不是分析起点。`题意理解` 是分析动作，不是正式核心要素。

## 4. 核心要素

选题分析固定形成六个核心要素。

### 4.1 主题

主题回答“这个题主要讨论哪一类问题”。

判断时检查：

- 问题范围是否明确，而不是过大的空泛概念。
- 是否足以约束后续的核心命题和切口。

### 4.2 目标用户

目标用户回答“这个题主要写给谁”。

判断时检查：

- 受众是否足够具体。
- 这群人是否真的关心这个问题。
- 这群人是否符合我方当前方向。

### 4.3 核心痛点

核心痛点回答“目标用户当前最需要解决什么问题”。

判断时检查：

- 问题是否真实、具体。
- 是否足以让目标用户停下来关注。
- 它是受众的问题，而不是创作者单方面想讲的内容。

### 4.4 收益承诺

收益承诺回答“用户看完后最有希望得到什么结果”。

判断时检查：

- 结果是否具体、可信。
- 是否直接回应核心痛点。
- 是否避免空泛好处或夸大承诺。

### 4.5 核心命题

核心命题回答“这条内容最终希望用户相信什么”。

判断时检查：

- 判断是否明确，而不是一句正确但无用的空话。
- 是否值得目标用户接受。
- 是否能够承接主题、痛点和收益承诺。

### 4.6 切口

切口回答“从哪个具体角度进入这个题”。

判断时检查：

- 是否便于目标用户理解和进入。
- 是否能把核心命题讲清楚。
- 是否与痛点和收益承诺一致，而不是同时展开多个方向。

### 4.7 一致性检查

核心检查三组关系：

- `主题 -> 核心命题 -> 切口`：问题范围、最终判断和进入角度是否属于同一条主线。
- `目标用户 -> 核心痛点`：这个问题是否确实属于这群人。
- `核心痛点 -> 收益承诺`：给出的结果是否真正回应当前问题。

任意一组不成立时，先判断原因是否已经清楚：

- 原因还不清楚：选题尚未分析清楚，继续讨论。
- 原因已经确认，但仍可能通过补资料或调整解决：可以形成 `暂缓`。
- 原因已经确认，并足以证明题目当前不成立：可以形成 `不建议做`，不得为了通过检查而编造一套自洽结论。

因此，一致性检查必须有明确结果，但不是所有正式结论都必须写成“一致性通过”。

## 5. 参考内容的使用

参考内容用于提供两类证据：这个题为什么可能成立，以及它是否适合我方。它不能代替六个核心要素和一致性判断。

使用时依次判断：

1. 参考内容本身是否成立，现有信息是否真的支持“质量好、数据好或用户认可”。
2. 它的选题与我方当前方向是否一致。
3. 它的切口是否适合我方直接使用，还是需要调整。
4. 调整后能否保留原本成立的核心逻辑。

参考内容存在正式 `内容分析.md` 时，本阶段只使用其中「借鉴判断」表的 `选题` 和 `切口` 两项借鉴判断；结构、表达留给内容生产阶段。（`内容画像与特征卡.md` 已于 2026-09-27 退役，不再作为借鉴判断的来源。）

最终只能形成三类处理方式：

- 方向和切口都适合：可以直接参考。
- 题目成立但与我方不完全匹配：保留核心逻辑后调整受众、痛点、收益、命题或切口。
- 样本本身证据不足或与我方明显冲突：不把它作为当前选题的主要依据。

## 6. 最终判断

六个核心要素都有明确的当前判断，并完成一致性检查后，才能形成最终结论。核心要素的当前判断可以是成立、待确认或明确不成立，但必须写清具体内容和原因，不能留空。

- `建议做`：核心要素自洽，一致性检查通过，符合我方方向，现有证据足以进入后续生产。
- `暂缓`：题目可能成立，但关键判断、证据或可修复的一致性问题仍会影响是否值得投入。
- `不建议做`：已经确认题目本身不成立、关键关系无法成立，或与我方当前方向存在明确冲突。

判断必须同时说明真正影响结论的理由，以及仍未被验证的边界。不得为了得到完整结论而补造证据，也不得把媒介形式、内容结构或正文建议混进选题判断。
