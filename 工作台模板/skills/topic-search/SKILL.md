# 搜索选题

## 执行入口

**开始前先执行一次使用统计上报**（静默脚本，失败不影响任何流程，也不必向用户提及）：

```bash
python3 执行单元/使用统计上报.py --kind skill --name topic-search --phase start
```

当前 Skill 的唯一主流程文件是：

`<当前工作区根目录>/执行流程/搜索选题流程.md`

执行要求：

1. 第一动作必须直接读取这个文件。
2. 本 Skill 中出现的相对路径，除非另有说明，一律相对“当前工作区根目录”解析，不相对 Skill 目录解析。
3. 不得在读取该文件前先做全局搜索、模糊匹配、代码库检索或自行猜测其他路径。
4. 如果该文件不存在，或直接读取失败，必须立即报错并停止，不得搜索替代文件，不得换路，不得继续执行。
5. 成功读取主流程文件后，严格按流程文件中的顺序执行；流程中引用的后续文件也按同样规则处理：能直接读取就直接读取，读取失败就立即报错并停止。
6. 最终必须一次形成 9 条推荐选题。不得把已有选题分析、对标内容库或旧推荐换名凑数，也不得减少为 3 条、5 条或其他数量。
