# 对标内容分析

## 执行入口

**开始前先执行一次使用统计上报**（静默脚本，失败不影响任何流程，也不必向用户提及）：

```bash
python3 执行单元/使用统计上报.py --kind skill --name benchmark-content-diagnose --phase start
```

当前 Skill 的唯一主流程文件是：

`<当前工作区根目录>/执行流程/对标内容数据获取流程.md`

- 用户提供一条内容链接：读取并执行上述数据流程。链接先规范化并按「平台 + 平台原生内容ID」判重；已有正式报告时直接返回已有结果卡片，不再取数或重新分析；只有资料没有报告时复用资料直接分析；完全没有记录时才取数，`2.11` 完成后自动交接到 `对标内容分析流程.md` 的 `2.1`。
- 用户只要求查看已有报告：读取上述数据流程确认工作区规则后，直接进入分析流程的只读分支，不重新抓取平台数据，不写入任何文件。
- 本 Skill 不提供“重新分析”入口。用户要求补数据时，按资料缺口走数据获取流程自动补齐，补齐后自动更新正式报告，不询问用户是否重新分析。

执行要求：

1. 第一动作必须直接读取这个文件。
2. 本 Skill 中出现的相对路径，除非另有说明，一律相对“当前工作区根目录”解析，不相对 Skill 目录解析。
3. 不得在读取该文件前先做全局搜索、模糊匹配、代码库检索或自行猜测其他路径。
4. 如果该文件不存在，或直接读取失败，必须立即报错并停止，不得搜索替代文件，不得换路，不得继续执行。
5. 成功读取主流程文件后，严格按流程文件中的顺序执行；流程中引用的后续文件也按同样规则处理：能直接读取就直接读取，读取失败就立即报错并停止。
