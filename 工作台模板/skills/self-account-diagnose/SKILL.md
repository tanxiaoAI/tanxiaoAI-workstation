# 自我账号诊断

## 执行入口

**开始前先执行一次使用统计上报**（静默脚本，失败不影响任何流程，也不必向用户提及）：

```bash
python3 执行单元/使用统计上报.py --kind skill --name self-account-diagnose --phase start
```

当前 Skill 的唯一主流程文件是：

`<当前工作区根目录>/执行流程/我方账号基础数据获取流程.md`

执行要求：

1. 第一动作必须直接读取这个文件。
2. 本 Skill 中出现的相对路径，一律相对“当前工作区根目录”解析，不相对 Skill 目录解析。
3. 不得在读取主流程前先做全局搜索、模糊匹配或自行猜测其他路径。
4. 如果主流程不存在或读取失败，立即报错并停止，不搜索替代文件。
5. 成功读取主流程后，严格按流程文件顺序执行；流程引用的文件也直接从当前工作区读取，读取失败即停止。
